# edge-shell

A customizable desktop shell for KDE Plasma (KWin Wayland), built with
[Fabric](https://github.com/Fabric-Development/fabric). It draws a thin frame
around each monitor and grows panels out of that frame. It runs alongside
Plasma and does not replace it.

Status: design phase. See the
[design spec](docs/superpowers/specs/2026-10-11-edge-shell-design.md).
